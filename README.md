# La Fuse Cosmetology Clinic - React Application

A modern, high-performance, responsive React web application built for **La Fuse Cosmetology Clinic** (Hair • Skin • Slimming).

## 🌟 Features

- **Brand-Centric Design**: Signature Warm Orange (`#E87500`) and Dark Charcoal branding with prominent La Fuse logo.
- **Hero Carousel**: Interactive auto-playing slide carousel highlighting core clinical treatments.
- **Vision & Mission Cards**: Custom cards matching official clinic references.
- **Specialization Grid**: Featured clinical care categories including **Hair Care**, **Skin Care**, **Weight Loss**, and **Laser Hair Removal**.
- **Success Stories**: Verified Google Reviews rating badge (4.9 ⭐⭐⭐⭐⭐) with before & after clinical progress cards.
- **Appointment Modal & Forms**: Interactive consultation booking popup modal and full contact request form.
- **Responsive Navigation**: Sticky header navigation drawer and mobile sticky quick-action bar (`📞 Call Now` & `📅 Book Visit`).

## 🚀 Tech Stack

- **React 18**
- **Vite 5**
- **Lucide Icons**
- **CSS3 Custom Properties** (Design Tokens)

## 🛠️ Local Development

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run Development Server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

3. **Build for Production**:
   ```bash
   npm run build
   ```
   The production static files will be generated in the `dist/` directory, ready for deployment to Vercel, Netlify, or Firebase Hosting.
